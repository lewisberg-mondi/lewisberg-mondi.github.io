How to install & use

Sideload the APK in a few steps, then start chatting and teaching Kanairoex.

1

Download the APK

Tap Download for Android on this page to save Kanairoex-AI.apk.

2

Allow install

In Android settings, allow installs from your browser or file manager (unknown apps).

3

Open the app

Launch Kanairoex AI. No sign-up. Your workspace starts empty and private.

4

Chat & teach

Type a message, try chips on the welcome screen, or teach facts with “Remember that…”.
