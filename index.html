How to install & use

Sideload the APK in a few steps, then start chatting and teaching Kanairoex.

1

Download the APK

Tap Download for Android on this page to save Kanairoex-AI.apk.

2

Allow install

In Android settings, allow installs from your browser or file manager (unknown apps).

3

Open the app

Launch Kanairoex AI. No sign-up. Your workspace starts empty and private.

4

Chat & teach

Type a message, try chips on the welcome screen, or teach facts with “Remember that…”.

Privacy by design

Built for people who want an assistant without handing over every conversation to a remote server.

📱

On-device storage

History, knowledge, and settings primarily live in local browser storage inside the app WebView.

🧹

You control reset

Use Clear in the app when you want a fresh start. Export tools help you back up memory when needed.

☁️

Online is optional

Research and some adapters need internet. Core chat and memory workflows are designed offline-first.

🔧

Experimental power tools

Wallet, token markets, and P2P are advanced / peer features — explore carefully.
