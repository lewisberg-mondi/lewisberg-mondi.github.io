About

            
Kanairoex is a fully client-side AI  built with pure HTML, CSS & JavaScript. It uses a blockchain-inspired memory structure, a growing knowledge base, simple reasoning rules, and mathematical evaluation. No data ever leaves your device.

            
Inspired by systems like Grok, ChatGPT and DeepSeek — but designed for private, offline ownership.
